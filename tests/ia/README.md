# Testes gerados por IA

Espaço reservado aos testes produzidos por IA sob protocolo comparável ao grupo manual. Registrar modelo, versão, prompt integral, contexto fornecido, saídas brutas, correções e tempo de validação.

O piloto preliminar feito com Python está preservado em `evidencias/`; ele não substitui uma suíte JUnit final nem a comparação controlada.
